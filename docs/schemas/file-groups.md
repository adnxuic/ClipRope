# File references and the drop effect

One `CF_HDROP` represents an ordered group of filesystem references. Capture accepts the Windows `DROPFILES` header and a double-NUL-terminated list of absolute drive or UNC paths. It accepts ANSI and wide input and stores a wide list in the same order, with a fresh header and no source-owned handles. The subset allows 1–1,024 references, up to 32,767 UTF-16 units per name and 4 MiB of descriptor bytes. Win32 device namespaces, named-pipe shares and relative paths are outside the subset. [Windows Shell format specification](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard)

Both the file list and the registered `Preferred DropEffect` use codec version 1, HGLOBAL, content aspect and index -1. For history the stored preferred effect is always the DWORD `DROPEFFECT_COPY`. The adapter supplies this companion descriptor when the source did not offer it. An orphan effect provides no usable representation. Capturing a cut does not republish or alter the native source object.

Before publishing a file group, the adapter verifies that every referenced path is available. A missing member fails the invocation before replacing the current clipboard, preserving the group for a later retry. ClipRope owns the saved path list. Deletion and GC operate on the history store's records and content files. A single image file and a pure image group publish only their paths and copy effect. Thumbnail pixels belong to a rebuildable cache. The file menu opens or locates the original and refreshes its availability and preview. [Image file decision](../decisions/0004-image-file-previews.md) [Adapter](../../src/platform_win/file_group.cpp) · [Shell round-trip fixture](../../tests/compatibility/file_group.cpp)

For a double-click bound to an Explorer folder, any real file selection publishes its ordered paths and copy effect. A selected shortcut contributes its own path and a selected directory contributes its root. For a pixel-only snapshot the folder publication adds a transient Unicode file descriptor and an indexed PNG stream. Neither the descriptor nor the stream becomes a history representation.
