# Supervise external paste target verification

The desktop records the original foreground and focused window identities before a card can change focus. It uses a native path for writable Edit and RichEdit controls. A complex target starts a sibling ClipRopeTargetWorker in the same window station and desktop, inside an active-process-limited, kill-on-close job. A pool callback launches and reaps the process. The desktop advances the gesture from its message loop. The CLI pumps messages while using the same protocol.

The 500 ms binding budget starts before session allocation. The 1,500 ms delivery budget covers modifier release, native focus restoration and final target verification. A replacement gesture, shutdown, changed publication, invalid reply or expired deadline suppresses input. A worker retains its UIA field on an MTA or Office selection or Shell folder view on a pumped STA. An inherited section and three bounded phase events carry serials and value results. The host owns the published data object, records the history attempt, revalidates the publication and destination, and sends at most one shortcut.

An unavailable helper leaves a successful publication available for manual use. Snapshot reads, OleSetClipboard, rendering published data and OleFlushClipboard have separate costs. The provider deadline does not bound those operations. Private station tests cover stopped synthetic providers and process reclamation. Real foreground focus, selected Office ranges and Explorer tabs require an unlocked test desktop.

During a Hanging card press, the workspace's installed mouse and keyboard hooks can witness pointer movement and left-button events on the nonactivating workspace while the worker obtains an Office selection. The temporary capture window for that press also forwards pointer movement and the first button release to its workspace owner. The hook checks the exact capture window and owner before accepting those events. The host accepts a changed last-input timestamp only when the hooks observed the new timestamp and the interval contained no other input. Without both hooks the original timestamp check applies. At delivery the worker reads the selection again, and the host rechecks the publication and foreground before sending Ctrl+V. The Office adapter uses the document pane under the original focus window.
