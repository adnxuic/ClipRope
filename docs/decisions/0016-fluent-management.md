# ADR 0016 · Fluent management surfaces

Color controls and color persistence are superseded by [ADR 0023](0023-unified-color-picker.md). The descriptions below record the original implementation.

**Accepted · 2026-11-02; boundary updated 2026-11-04.** Sections 6–7 of the implementation plan and the card and rope menu decisions define command outcomes. The management surfaces share one warm neutral theme, DIP metrics, typography, focus treatment and input components. Workspace materials and Rich Edit input keep their specialized rendering. Inline save/cancel actions now use shared Fluent icons, transitions and focus rings over their existing paper texture in all four paper-editing contexts.

The [UI design contract](../developer/ui-design.md) is the normative specification for
new components and all reachable visual states. Shared native list/choice adapters
own expanded borders, rows and scrolling while retaining native input and accessibility.
All short help uses the nonactivating Fluent Tooltip. The
[mandatory checklist](../../.agent/ui-checklist.md), CTest source/interaction gates and
source-bound visual acceptance records apply to UI changes. The system folder picker,
IME candidate windows and pre-UI startup failure message remain platform-owned exceptions.

The tray uses the card and rope menus' composited frame and native accessible buttons. At five previews the face is 224 × 228 DIP. Previews use 12-DIP regular text and a 21-DIP row. The header pairs the current-rope label with the 14-DIP semibold rope name on the same line. Shorter ropes omit the unused rows. The current-rope header opens the workspace and leaves an already visible workspace open. The notification icon and workspace shortcut toggle visibility. The preview band holds the first five Hanging summaries at most. Digits 1–5 invoke the displayed IDs and H invokes the first displayed ID through the rope-head route. Each command validates membership of the bound rope before publishing. An empty rope displays “No recent cards.” Beneath the previews, **Quick note** shows a paper-and-pencil icon and its global shortcut. Selecting it transfers keyboard focus to the new paper editor. S opens Global settings and X exits. Escape dismisses the popup and returns keyboard access to the notification area. [Tray reference](../../tests/compatibility/fluent/ui14-tray.png)

On a bottom taskbar the face opens upwards with its lower-left corner two DIPs above the icon's upper-left corner. The notification icon's screen rectangle anchors mouse and keyboard openings. If Explorer reports the overflow button while the event is inside the open flyout, the clicked point anchors the menu. Windows keeps the face inside the icon monitor's work area, slides it horizontally when needed and can open it below an icon near the top. The transparent shadow does not widen the placement gap. [Notification area guidance](https://learn.microsoft.com/en-us/windows/win32/uxguide/winenv-notification#context-menus) · [Icon rectangle](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyicongetrect) · [Popup positioning](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-calculatepopupwindowposition)

The activatable Settings Center has seven categories. General configures sign-in, workspace stacking and a confirmed reset of global preferences. [General settings](0020-general-settings.md) The Shortcuts page reads live bindings and applies per-action changes. Cards edits the Hanging action, inherited text size, original-resolution caption, single-file thumbnails and group retention. Ropes sets the initial capacity for new ordinary ropes. Appearance and Storage & Privacy use the controls defined in [ADR 0019](0019-appearance-and-profile-location.md). Capture exclusions are under Privacy. A workspace registration conflict opens Shortcuts and the tray remains available.

The settings window opens on General on its first visit, then restores the selected category for the process lifetime. Switches and list selections save immediately. Numeric fields commit on Enter or focus loss and discard the draft on Escape. A failed save restores the committed value and reports the reason in the row. [Card and rope preferences](../../Tasks/SETTINGS-cards-ropes.md)

The seven settings pages share a clipped child window below the title-bar drag area. The sidebar and close button stay on the frame. Measurement records the row bounds in document coordinates. Wheel input, keyboard focus and the scroll thumb project those bounds into the same viewport. The viewport owns its background and forwards native control notifications. A scrolling layout moves its children in a batch, discards old client pixels and invalidates the viewport and its descendants after placement. Height-limited menus use their own client area for the same operation.

Settings, Card information and File information use the same Fluent vertical scroll bar. The thumb appears when content overflows and supports dragging, track paging, keyboard input and Windows wheel preferences. UI Automation exposes Scroll on the container and RangeValue on the bar. Rich Edit retains the text, selection and document scroll position in the information dialogs. The bar follows the measured document and sends scroll requests back to the editor. [Shortcut page](../../tests/compatibility/fluent/shortcuts-compact-light.png) · [Scroll qualification](../../Tasks/FLUENT-management.md#ui-13--management-window-scrolling)

Daily dialogs use a single client-area heading and close button inside a DWM-composed frame. Card information and file diagnostics present selectable text. The format inventory and the plain-text report share structured rows, including per-format outcomes and indices. Rope operations retain their preview, consent and commit stages. Closing a form cancels its current operation. The folder chooser uses the same composited underlay as the card and rope menus. [Card information](../../tests/compatibility/fluent/ui14-card-information.png)

The rope and card popup hosts native accessible controls. Clicking a swatch or toggling Bold applies to the pointed entry. Enter commits a typed value, ending a slider gesture commits its final position and Escape discards unsubmitted text. Local rope properties use the existing preview and stamped commit. A shrink, clear or deletion requires confirmation. Ownership, clipboard publication, history order and persistent formats retain their existing contracts.

Card and rope menus use the tray's 14-DIP semibold heading and 12-DIP regular text. Single-line commands occupy 24 DIP, property rows 28 DIP and descriptive actions 36 DIP. The text-card face measures 288 × 248 DIP. Command-only cards use a 248-DIP width and take their height from the available actions. The card header identifies the content type. A Hanging card displays its one-based position and total on its own rope. A detached card displays Floating. The editable text menu groups the font stepper, Bold, five text colors, five paper colors and opacity above two single-line actions. Clicking a value enters precise editing. Clicking a color label exposes its hex field. Enter on the newly opened text menu opens the inline editor. The entry's saved style determines the visible values. The second line of the style band groups the name, four color swatches and the capacity stepper. Edit style opens the complete properties dialog, including custom hex entry. The density and overview selectors show the current state. Choosing the selected segment keeps the menu open. The ReBin switch reports its current visibility. A protected rope adds 12 DIP for the reason below its disabled Delete action. Both menus share the composited frame and native input controls. ### Opening a management menu

The pointed view supplies a value snapshot of the entry or rope, its displayed position and its current controls. When a legacy single path has an unknown kind, the first frame offers Reveal and Refresh. A preview-worker result can add the type-specific commands to the same open window after matching the entry, snapshot and revision. A stale result closes the pending menu. Command execution rechecks the live target.

The popup saves the native foreground and focused child before activation. Dismissal restores that child only while ClipRope still owns the foreground and the receiving window has not selected another field. The next actual paste gesture binds the editor and revalidates it before sending input. The menu renderer reuses its software DC target and device-independent formats on the UI thread. The shadow cache retains up to 8 MiB, and the static control artwork cache retains up to 4 MiB. [UI qualification](../../tests/performance/README.md#context-menu-latency)
