Getting started

Try ClipRope in Notepad. Copy two lines, then paste the first one from your history.

Open ClipRope

Run the Windows x64 installer, then open ClipRope from the Start menu. Look for the wooden hanger icon in the taskbar notification area. If you don’t see it, open the hidden icons.

Click the icon or press Ctrl+Shift+V to show or hide the workspace. The current rope keeps collecting what you copy while the workspace is hidden.

A fresh installation enables Start with Windows by default; an upgrade keeps your existing choice. If setup says ClipRope is running, choose Exit from the tray menu, then retry. See setup options and how to keep history when uninstalling.

The open workspace has a taskbar button. Closing it from the taskbar, or pressing Alt+F4 while the workspace has focus, hides the workspace and leaves capture running. Esc does not dismiss an idle workspace. To stop ClipRope, choose Exit from the tray menu.

Paste an earlier copy

  1. Copy two lines of text.

    In Notepad, type “Meeting room” on one line and “Wednesday morning” on another. Select and copy each line separately, in that order. Put the cursor on a blank line where you want to paste.

  2. Find the earlier line.

    Press Ctrl+Shift+V. “Wednesday morning” is the first card on the rope. “Meeting room” is the next one.

  3. Double-click the paper on the “Meeting room” card.

    ClipRope restores the text to the clipboard, moves the card to the front of its rope and hides the workspace. By default, it sends one Ctrl+V to the original editor if that editor can still accept a paste. Check the blank line for “Meeting room”.

When to paste manually

If you chose Copy only, or no writable destination was selected when you opened the workspace, the card’s contents are still available after a successful copy. Click where you want them and press Ctrl+V.

If ClipRope reports “Copied. Paste shortcut sent.”, check the destination before pressing paste again. The receiving app decides which clipboard format it can use.

Recall recent cards from the tray

Right-click the ClipRope icon in the notification area. Click the current rope’s name at the top to open the workspace. Below it are up to five cards from the front of that rope. Click a preview or press 1–5 (including the numeric keypad) to copy that card to the clipboard and move it to the front. Click the destination and press Ctrl+V to paste. Press H to recall the first card.

The same menu offers Quick note, Global settings (S) and Exit (X). If a Floating card is hidden, choose Show a hidden Floating card to try restoring one. Choose it again to cycle through other hidden cards. These single-key commands work only while the tray menu is open.

Select ClipRope in the notification area using the keyboard and press Enter to toggle the workspace, just like a left-click. The middle button has no assigned action. ClipRope restores its tray icon after Windows Explorer restarts.

Try the interactive demo

The browser demo includes a sample chat and folders. Try copying a message, recalling it from history, and dragging a card back onto a rope.
