Default shortcuts and where they work

Press Ctrl+K to search this guide. To change the app’s configurable shortcuts, open Global settings → Shortcuts.

Find text in your cards

Open the workspace, point at a rope row and press Ctrl+F, or choose Find in Cards from the rope menu. Enter text, a link or part of a file path. Press Enter for the next match, Shift+Enter for the previous one, or Esc to close.

Single-rope view searches the current rope. Overview searches across ropes, including ReBin when it is visible. Find uses the information saved on each card. It does not read file contents or recognize text in screenshots. Moving between matches leaves the collecting rope and clipboard as they were.

Nothing appeared after a double-click

The card moved to the front, but the destination is empty
Check Global settings → Cards for Copy only. If the contents were copied, click the intended destination and press Ctrl+V. Automatic paste requires the original input area to still be available.
“Copied. Paste shortcut sent.”
Check the destination before pasting again to avoid a duplicate. The receiving app chooses a format it supports. Try Notepad for text, or a File Explorer folder for a file, a folder or a screenshot PNG.
“Clipboard publication failed. The card is still available.”
ClipRope could not restore the contents to the clipboard. Try the card again from its rope. If it references a file, check that the original is still accessible at its saved path.

Common questions

Where is the Floating card I closed?
By default it goes to the front of ReBin. Show ReBin and recover the card.
Why did scrolling switch ropes?
In single-rope view, the wheel browses cards. Holding Ctrl while scrolling switches collecting ropes. Compare wheel gestures in both views.
Will my cards be there after a restart?
ClipRope reloads saved Hanging and Floating cards from local history. Cards that reference external files still depend on the originals. Find your data folder.
