Default shortcuts and where they work

Press Ctrl+K to search this guide. To change the app’s configurable shortcuts, open Global settings → Shortcuts.

Hover shortcuts do not respond: Clicking the paper or rope normally leaves keyboard focus in the original app. With the workspace open, select its ClipRope taskbar button or switch to it with Alt+Tab, then use the shortcut. If a notice refers to “Keyboard navigation” in the rope menu, the current menu has no such item. Choose Next rope, Rope overview or Find in Cards directly instead. Hide and reopen the workspace to retry hover detection.

Find text in your cards

Open the workspace, point at a rope row and press Ctrl+F, or choose Find in Cards from a rope menu. Find searches Hanging cards only; it skips Floating cards on the desktop. Single-rope view searches the current rope. Overview searches across ropes, including ReBin when visible.

Search for text (including saved HTML or RTF body text), links, part of a file path, a virtual filename or the source app name, such as notepad.exe. Find does not read the contents of referenced files or recognize text in screenshots.

In the search field, press Enter or ↓ for the next match, Shift+Enter or ↑ for the previous match, or click the arrow buttons. Press Ctrl+F again to select the query or Esc to close. Browsing matches leaves the collector and clipboard unchanged.

Find ignores case for ASCII A–Z only and matches other characters as typed. If a match is on an image, on a fully transparent card, or in a field not normally shown (such as a path or source), look for the highlighted excerpt at the bottom of the paper.

Nothing appeared after a double-click

Read the message for two separate results: whether the contents reached the clipboard and whether ClipRope sent a paste to the original window. Moving the card to the front is a separate history update.

“Copied.” or “Copied. The selected field could not receive this item.”
Click a destination that accepts the content and press Ctrl+V. If you always need to paste manually, check Global settings → Cards → Hanging double-click for Copy only.
“Copied. Paste shortcut sent.” or “Copied. Paste shortcut dispatch was uncertain.”
Check the original destination first to avoid a duplicate. If it is still empty, paste manually into a compatible destination, such as Notepad for text or a File Explorer folder for a file or screenshot.
“Clipboard publication failed. The card is still available.”
Do not assume the clipboard contains this card. Open Card information… to check its saved formats and paths, confirm the originals are accessible, then try the card again.
The message ends with “The history update failed.”
Moving the card to the front can fail even after copying succeeds. Check the destination first, then the storage tips below. There is no need to paste again to fix the order.
“Clipboard was not updated.”
A rope switch or first-card change may have been saved even though the clipboard did not follow. Recall the intended card explicitly and confirm the copy before pasting.

Where can a copied card paste automatically?

Select the destination before double-clicking. ClipRope sends Ctrl+V only if it can verify the same writable destination again. For example, a normally launched ClipRope cannot send paste to a window running as administrator. If the notice says “Copied.”, return to a destination you can edit and paste manually.

Word, Excel and PowerPoint
The document and selection must still be editable. Word checks an ordinary body selection; protected documents and content controls do not qualify. Excel checks the workbook, selection and active cell; a locked cell on a protected worksheet does not qualify. PowerPoint checks the pane, slide or selected objects. A read-only file or a changed selection can prevent automatic paste.
Image files copied in File Explorer
The card offers references to the original files. A folder can copy the files; a web composer that accepts attachments, an Office selection or a compatible rich text field can use its own paste handler. Notepad and browser address bars are not automatic file-paste targets. Even after “Paste shortcut sent”, check whether the receiving app actually inserted the attachment.

When history cannot be read or saved

Folder not writable · Store busy · Disk full
Check the active folder in Storage & Privacy and confirm you can access and write to it. If the store is busy, exit any other instance using that history from its tray menu. If the disk is full, free space on that drive and retry.
Missing or damaged saved content · Damaged database
Keep the existing data folder. Check that it is the intended history and use a verified backup if recovery is needed. For a missing external file, check its original path in Card information… first.
Unsupported database version
This release requires a v11 database. Verify the profile path and use a version or backup compatible with that history. Resetting global settings does not convert a database.

Clipboard and virtual file limits

ClipRope examines up to 256 format descriptors per copy and retains up to 64 MiB in total. Copying an ordinary file in File Explorer saves a reference to its path, so the file’s size on disk is not the size of the card. For a partial capture, check Card information to see which formats were kept.

Capture limits per format
FormatLimit
Unicode text, HTML, RTF8 MiB each.
PNG, DIB, DIBV532 MiB each; at most 8,192 pixels per side and 8,388,608 pixels in total.
File path list (CF_HDROP)4 MiB for the path list, independent of the referenced files’ sizes.

Some apps supply virtual files: streams delivered to the receiving app instead of paths to existing files. A group can contain up to 16 files, at most 8 MiB each and 32 MiB in total. Keep ClipRope running until the paste finishes. On normal exit, if its virtual files are still on the clipboard, ClipRope removes the virtual file formats and keeps independent companion formats such as text. If there were only virtual files, no files remain available to paste. Reopen ClipRope and recall the saved card to make them available again.

Pasting a pixel-only screenshot to the previously selected File Explorer folder offers a PNG named with local time: Screenshot-YYYYMMDD-HHMMSS-mmm.png. Dragging to a folder can copy a verified original image file instead; otherwise it offers the same timestamped PNG.

Install, launch and uninstall options

Install or update
Exit ClipRope from the tray before running setup. On a first installation, choose a new or empty local folder. Use /S to run the installer silently. The installer accepts /STARTUP or /NOSTARTUP to set the sign-in choice. To choose a first-install path, put /D=D:\My Apps\ClipRope last without quotes. Upgrades use the registered folder; if a previous version is available, /ROLLBACK restores that program version in place.
Launch ClipRope.exe
--show opens the workspace at launch. --profile "D:\ClipRope-Test" selects a separate history folder for this run, useful for testing. An uninstalled development build requires this option; without it the program exits silently with code 2 without opening daily history. On normal exit, --export-diagnostics-on-exit writes session counters to diagnostics.txt in the active data folder. It contains no clipboard body or file paths. Export is refused if the report exceeds 4,096 bytes or the destination folder is a reparse point.
Uninstall and keep history
For the installed app, use Windows Installed apps. Choose Yes (the default) when asked whether to keep history and local backups for a later installation. Choosing No, or passing /PURGEHISTORY to the installed uninstaller, requests deletion of this profile’s history, Floating cards and local backups. Silent uninstall with /S alone keeps data; only combining it with /PURGEHISTORY requests deletion. Deletion may be blocked if another copy owns the sign-in registration.
Remove a development build
Run the Uninstall.exe from that build’s own folder. Data is kept by default. Enable the deletion switch only if you intend to remove the daily profile’s history and backups. Separate --profile folders are not part of this cleanup.

Common questions

Where is the Floating card I closed?
By default it goes to the front of ReBin. Show ReBin and recover the card.
Why did scrolling switch ropes?
In single-rope view, the wheel browses cards. Holding Ctrl while scrolling switches collecting ropes. Compare wheel gestures in both views.
Will my cards be there after a restart?
ClipRope reloads saved Hanging and Floating cards from local history. Cards that reference external files still depend on the originals. Find your data folder.
