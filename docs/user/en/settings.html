Settings and privacy

Right-click the tray icon and open Global settings to change double-click behavior, exclude apps from capture or move your local history.

On this page

  • Set double-click to Copy only

  • Exclude an app from clipboard capture

Change language, window position and sign-in behavior

Open Global settings → General. Language offers Auto (follow Windows), English and 简体中文 and changes immediately. Always on top is on by default and keeps the rope workspace above other windows.

Turn on Start with Windows to have ClipRope appear in the notification area at sign-in. A separate profile opened with --profile cannot manage sign-in. For the app version and storage engine (SQLite), open About ClipRope.

Reset settings… asks for confirmation. It restores card preferences, new-rope capacity, shortcuts and appearance; turns on Always on top; and sets the language to Auto. On a daily installation that manages sign-in, it also enables Start with Windows. History, individual card and rope styles, the data folder and capture exclusions are kept.

The minimum Settings window is 680 × 480 DIP. Below a content width of 760 DIP, the sidebar shows category icons only; widen it to see the names. In Font size or Capacity for new ropes, press Enter to apply or Esc to restore the saved value. On a theme option, ← / → changes the theme. Outside an input or drop-down, use PageUp, PageDown, Home or End to scroll the page.

Set double-click to Copy only

Open Global settings → Cards → Hanging double-click. The default, Copy and paste, sends a paste to the original destination if it can still accept one. Choose Copy only to restore the contents to the clipboard, move the card to the front of its rope and hide the workspace. Click where you want the contents and press Ctrl+V.

On the same page, Hanging card deletion and Floating card deletion control what × does in each form. See which closed cards you can recover from ReBin.

Set text size, image previews and file group behavior

Cards → Font size (DIP)
The default is 14; values from 6 to 96 are accepted, including decimals. A font size set on an individual text card takes priority.
Show original resolution on hover · Screenshot hover preview · Show image file thumbnails
All three are on by default and work independently. To see pixel dimensions without a full screenshot preview, leave the first on and turn off the second. The third controls thumbnails on image file cards.
Keep original group after expansion
On by default. Turn it off to replace the original group with member cards when you expand a file group.

Choose when the first card updates the clipboard

Ropes → Update clipboard when switching ropes
On by default. Switching to a nonempty collecting rope copies its first card to the clipboard for your next manual paste.
Cards → Update clipboard when the first card changes
On by default. When you rearrange the current collecting rope and a different card becomes first, its contents are copied. Saving an edit to the first card’s text also updates the clipboard.

Scrolling through cards, canceling a drag or switching to an empty rope leaves the clipboard as it was. Neither setting sends a paste shortcut to another window.

Ropes → Capacity for new ropes sets the starting limit for ropes you create later. The default is 100; enter a whole number of at least 1. This does not trim existing ropes. To change one, use its Edit style… command.

Exclude an app from clipboard capture

  1. Open Storage & Privacy → Clipboard capture exclusions and choose Edit list….
  2. Enter the app’s executable name, such as KeePass.exe, and choose Add. Enter the filename without its folder path.
  3. Choose Save. Future copies from the listed apps are skipped. Cards already in your history stay there.

Add up to 64 executable names of at most 255 characters each. Names are case-insensitive; paths, wildcards and duplicates are rejected. If Save reports a pending name, click Add or clear the input first. Closing the editor discards unsaved list changes.

ClipRope also honors Windows privacy flags on each copy, even for apps outside the list. It skips a copy if the app supplies ExcludeClipboardContentFromMonitorProcessing, or supplies CanIncludeInClipboardHistory with a value other than 1. A flag that only blocks cloud sync still allows local capture. To skip every copy from an app, add its executable to the list.

Find or move your history folder

The default data folder is %LOCALAPPDATA%\ClipRope. Open Storage & Privacy to see the active Data folder and its Disk usage. ClipRope stores history and Floating card positions on this PC. Referenced files remain in their original locations.

Choose Browse… beside Data folder and select an existing, writable, empty folder on a local drive. A drive root, network share or path through a symbolic link, junction or other reparse point is not eligible. The destination must be separate from both the active history folder and %LOCALAPPDATA%\ClipRope.Settings: it cannot equal, contain or sit inside either. Choose Restart now to start the move, or Later to keep using the current folder until the next launch. Use Cancel move to cancel a pending migration.

If the path is marked as supplied by --profile, this session is using the separate history folder passed at launch. See launch options and uninstall choices.

Disk usage shows the space allocated to recognized history data, backups, thumbnails and registered screenshots. It uses B, KiB, MiB or GiB (1,024 of one unit make the next). Unrelated files and unregistered screenshots are excluded, so the number can differ from the folder size in Explorer.

Customize shortcuts and appearance

On the Shortcuts page, turn each action on or off separately. Select a binding to record a combination, press Esc to cancel, or choose Check to check availability. If Windows cannot register the enabled workspace shortcut at startup, ClipRope opens Settings. The tray icon still opens the workspace. See default shortcuts and their scope.

Use A–Z, 0–9, Space, Tab or F1–F24 with Ctrl, Alt or Shift. The Windows key and combinations of Alt with Tab are unsupported. Global shortcuts require a modifier and cannot use F12. Only hover shortcuts accept Tab or a function key on its own.

✓ Registered · ✓ Available · Available (off)
The global binding is registered; the hover binding works on hover or workspace focus; or the binding passed its check but is switched off, respectively.
Not verified · Limited · Unavailable
For Not verified, open the workspace once. Limited means hover detection failed. Focus the workspace from the taskbar and retry; note any Windows error code. For Unavailable, check the conflict or invalid-key message and try a different combination.

Under Appearance → Theme, select Light, Dark or System. Find highlight color marks the current match on a card. The theme button at the top of this guide changes only the guide.
