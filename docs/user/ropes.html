整理绳子

用不同的绳子整理不同任务。当前收集绳接收新复制的内容，每根普通绳子有自己的顺序和容量。

创建、切换收集绳

右键单击绳线或中央的木质名牌，选择新建绳子…。输入名称（不能全是空格，最多 256 个 UTF-16 单元，部分字符占两个），选择颜色，填入正整数容量。保存后，在切换提示中选择是，之后复制的内容就会挂到新绳上。

指针位于绳子行上或工作区获得焦点时，按 Tab 选择下一条收集绳。在单绳视图里也可按住 Ctrl 滚动滚轮：向上切到上一条，向下切到下一条。切到非空绳子时，默认会把新绳的首张卡片复制到剪贴板。调整绳首与剪贴板的联动

在总览中浏览和排序

将指针移到绳子行上，按 Ctrl+Tab 切换单绳视图与总览。在总览中双击某行的绳线或名牌，可把它选为收集绳并进入单绳视图。

在两种视图中操作绳线或名牌
手势单绳视图多绳总览
滚动滚轮沿当前绳子浏览卡片。沿指针所在的行浏览卡片。
Ctrl + 滚轮切换收集绳。上下浏览绳子列表，收集绳保持不变。
上下拖动绳线或名牌保存这根绳子在屏幕上的高度。拖到行间调整绳子顺序。排在首位的绳子负责收集。

支持横向滚轮的鼠标也可以左右浏览指针所在行的卡片。总览中拖动绳线或名牌排序时，在总览工作区外松手会取消这次重排。

移动或复制卡片

要移动一张卡片，按住纸面中央拖向目标绳，等相邻卡片让出空位再松手。要够到屏幕外的位置，把指针停在那一行的左端或右端，让它滚动。按 Esc 取消。

要复制，先按住 Ctrl 再拖动纸面。复制到哪里取决于开始拖动时的视图：

多绳总览：复制到绳子
从绳上卡片或桌面悬浮卡片拖到任一可见绳子的空位。拖动悬浮卡片时，原卡仍留在桌面；在所有行外松手会取消复制。目标绳仍受容量限制。
单绳视图或工作区收起：复制到其他应用
从单绳上的卡片拖到能接收它的应用。悬浮卡片在单绳可见或工作区收起时也可以这样拖出。在资源管理器文件夹松开可复制文件；拖出截图可得到图像文件。想在同一根绳上复制卡片，先打开总览。

拖到外部应用时，若改变主意，可在松开左键前按鼠标右键或 Esc 取消这次拖放。

用绳子菜单调整或清理一根绳

右键单击要操作的绳线或名牌；总览中，菜单操作的是你点中的那一根绳。

编辑样式… · 卡片密度
在菜单里直接改名称、颜色或容量；用 − / + 微调或输入数值。缩减容量前可核对将被移除的绳尾卡片。密度可选“紧凑”或“常规”，每根绳单独记住。
返回首张卡片 · 上一条绳子 / 下一条绳子
“返回首张卡片”只把视图滚到绳首，不复制卡片。上一条、下一条则切换收集绳。
绳子总览 · 查找卡片 · 显示／隐藏 ReBin
在“全部绳子”和“当前绳子”间切换，搜索绳上的记录，或找回移入 ReBin 的卡片。
新建绳子… · 清空绳上卡片… · 删除此绳子…
清空会保留绳子；删除会连绳子一起移除。两者都会在确认前显示受影响的绳上卡片数量，悬浮卡片仍保留。主绳和系统 ReBin 都不能改名或删除；ReBin 的容量固定为无限。

绳满时会移除哪张卡片？

每根普通绳子单独计算容量。第 1 张位于绳首，最后一张位于绳尾。新复制或通过回绳按钮返回的卡片加入首位，超出容量时移除这根绳子末尾的卡片。

原先排在末尾的 C 被移除。其他绳子上的卡片不受影响。如果回绳操作保存失败，A、B、C 保持原顺序，D 仍在桌面上。

调整现有绳子的容量，可右键单击绳线或名牌，选择编辑样式…。缩减容量需要确认。全局设置 → 绳子 → 新绳默认容量用于之后新建的绳子。
