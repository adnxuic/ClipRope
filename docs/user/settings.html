设置与隐私

右键单击托盘图标，打开全局设置。这里可以更改双击动作、指定哪些应用跳过捕获，或把历史记录迁移到其他文件夹。

更改语言、置顶和登录启动

打开全局设置 → 常规。“语言”可选“自动（跟随 Windows）”、English 或简体中文，选择后立即生效。“工作区置顶”默认开启，控制绳子工作区是否盖在其他窗口上。

打开“随 Windows 启动”后，登录时 ClipRope 会出现在通知区域。用 --profile 打开的独立配置不能更改登录启动。需要核对版本时，到关于 ClipRope查看版本号和存储引擎（SQLite）。

重置设置…需要确认，会恢复卡片偏好、新绳容量、快捷键和外观，重新启用工作区置顶，并把语言设为自动。在可管理登录启动的日常安装中，也会开启登录启动。已有历史、单卡和单绳样式、数据目录与捕获排除列表都会保留。

设置窗口最小尺寸为 680 × 480 DIP；内容区宽度不足 760 DIP 时，左侧只显示分类图标，加宽可重新看到名称。在字号或新绳容量输入框中，Enter 应用输入，Esc 恢复已保存的值。在外观主题选项上用 ← / → 切换主题；焦点不在输入框或下拉选择框时，可用 PageUp、PageDown、Home、End 浏览页面。

让双击仅复制

打开全局设置 → 卡片 → 绳上卡片双击操作。默认的复制并粘贴会向仍可接收内容的原目标发送粘贴。选择仅复制后，双击会恢复剪贴板内容、把卡片移到所属绳首并收起工作区。随后由你选择位置并按 Ctrl+V。

同页的绳上卡片删除方式和悬浮卡片删除方式分别控制两种卡片的 ×。查看回收和直接删除的区别

调整字号、图片预览和文件组

卡片 → 字号（DIP）
默认 14，可设为 6–96 之间的数值，支持小数。单张文字卡片上设置的字号优先。
悬停时显示原始分辨率 · 截图悬停全图预览 · 显示图像文件缩略图
三项默认都开启，且相互独立。只想看图片尺寸就保留第一项；不想让截图放大就关闭第二项；文件卡片是否显示图片缩略图由第三项控制。
展开后保留原文件组
默认开启。关闭后，展开文件组会用成员卡片替换原组。

切换绳子或首卡时更新剪贴板

绳子 → 切换收集绳时更新剪贴板
默认开启。切换到有内容的收集绳时，ClipRope 将它的第一张卡片复制到剪贴板，供下次手动粘贴。
卡片 → 首卡变化时更新剪贴板
默认开启。手动调整当前收集绳后，如果首卡改变，或首卡文字的修改已保存，剪贴板随之更新。

仅滚动浏览、取消拖动或切到空绳时，剪贴板保留原内容。上述两个选项只负责更新剪贴板，不会向其他窗口发送粘贴。

绳子 → 新绳默认容量决定以后新建的绳子默认能挂多少张卡片。默认是 100，只接受不小于 1 的整数。改这项不会缩减现有绳子；要更改已有绳子的容量，请用它的编辑样式…。

排除指定应用的捕获

  1. 在存储与隐私 → 剪贴板捕获排除列表中选择编辑列表…。
  2. 输入应用的可执行文件名，例如 KeePass.exe，然后选择添加。文件名不需要包含路径。
  3. 选择保存。之后从列表内应用复制的内容将跳过捕获；先前已保存的卡片仍在历史记录中。

最多添加 64 个程序，每个文件名最多 255 个字符，不区分大小写。不接受路径、通配符或重复项。若“保存”提示还有待添加的名称，点“添加”或清空输入框后再保存；关闭编辑器会放弃未保存的列表修改。

即使应用不在排除列表中，ClipRope 也尊重该次复制携带的 Windows 隐私标记。应用提供 ExcludeClipboardContentFromMonitorProcessing，或提供 CanIncludeInClipboardHistory 但其值不是 1 时，这次复制不会进入历史。只禁止云同步的标记不影响本地捕获。若希望某个应用的所有复制都跳过，请将它加入列表。

查看或迁移历史目录

日常使用的默认数据目录为 %LOCALAPPDATA%\ClipRope。在存储与隐私中查看当前数据目录和磁盘占用。历史和悬浮卡片位置保存在本机；引用的外部文件仍在原位置。

要迁移历史，在数据目录旁选择浏览…，选择本地磁盘上已有、可写的空文件夹。目标不能是盘符根目录或网络共享，路径中不能经过符号链接、目录联接等重解析点。目标必须与当前历史目录、%LOCALAPPDATA%\ClipRope.Settings 分开：不能是这两者本身，也不能是它们的上级或子目录。选择立即重启可开始迁移；选择稍后会继续使用当前目录，直到下次启动。迁移前可选择取消迁移。

看到“此路径由 --profile 指定”时，当前运行的是独立历史目录；这次启动使用命令行给出的路径。查看启动参数与卸载时的数据选择。

“磁盘占用”显示已识别的历史数据、备份、缩略图以及已登记截图在磁盘上占用的空间，按 B、KiB、MiB 或 GiB 显示（每级相差 1,024 倍）。自行放入的无关文件和未登记的截图不计入，因此数值可能与资源管理器的文件夹大小不同。

自定义快捷键与外观

在快捷键页可单独启停每个操作。点组合键录制新按键，按 Esc 可取消。点检查验证可用性。若启动时无法注册已启用的工作区唤出键，ClipRope 会打开设置；仍可从托盘打开工作区。查看默认键位和生效范围。

可使用 A–Z、0–9、Space、Tab 或 F1–F24，配合 Ctrl、Alt、Shift；不支持 Win，也不能把 Alt 与 Tab 搭配。全局快捷键必须带修饰键，且不能用 F12。只有悬停快捷键允许单独使用 Tab 或功能键。

✓ 已注册 · ✓ 可用 · 可用（已关闭）
分别表示全局组合键已注册、悬停或工作区焦点下可用、组合键通过检查但开关未开启。
尚未验证 · 受限 · 不可用
尚未验证时，先打开一次工作区。受限表示悬停检测失败；可通过任务栏聚焦工作区后再按，并记下提示中的 Windows 错误码。“不可用”时查看冲突或无效按键提示，换一组键再检查。

在外观 → 主题选择浅色、深色或跟随系统。“查找高亮颜色”标出卡片中的当前匹配。手册页顶的主题按钮只改变网页显示。
