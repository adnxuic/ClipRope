快速开始

在记事本里复制两段文字，再取回第一段。这个例子会用到工作区、绳上卡片和一次粘贴。

启动并找到托盘图标

运行 Windows x64 安装程序，完成后从开始菜单打开 ClipRope。在任务栏通知区域找到衣架图标；如果图标被折叠，可以展开隐藏图标。

左键单击图标或按 Ctrl+Shift+V 可显示或收起工作区。工作区收起后，当前绳子仍会收集新复制的内容。

首次安装默认勾选随 Windows 登录启动；升级会沿用现有选择。如果安装程序提示 ClipRope 正在运行，从托盘菜单选择退出后再试。安装选项和卸载时如何保留历史。

工作区打开时，任务栏会显示它的窗口按钮。在任务栏关闭该窗口，或在工作区已获得焦点时按 Alt+F4，都只会收起工作区，ClipRope 会继续收集。空闲时按 Esc 不会收起工作区。要停止程序，请用托盘菜单 → 退出。

找回第一段文字

  1. 复制两段不同的文字。

    在记事本中分别选中并复制“会议地点”和“周三上午”，再把光标放到希望插入文字的空行。

  2. 打开工作区，找到“会议地点”。

    按 Ctrl+Shift+V。“周三上午”排在绳首，先前复制的“会议地点”在它后面。

  3. 双击“会议地点”的纸面。

    这张卡片的内容会恢复到剪贴板，卡片回到所属绳子的首位，工作区收起。默认情况下，如果原编辑器仍可接收粘贴，ClipRope 会向它发送一次 Ctrl+V。先查看空行里是否已出现“会议地点”。

什么时候手动粘贴？

选择了仅复制，或者唤出工作区前没有可用的输入位置时，双击仍会把卡片内容放回剪贴板。点到希望插入的位置，按一次 Ctrl+V。

如果看到“已复制，已发送粘贴快捷键。”，先看目标应用的结果，再决定是否手动粘贴。编辑器或文件夹会自行选择可接收的格式。

从托盘取回最近的卡片

右键单击通知区域的 ClipRope 图标。点顶部的当前绳名可打开工作区；其下最多列出该绳前五张卡片。点预览或按 1–5（小键盘也可）把对应卡片复制到剪贴板，并移到本绳首位。点回目标窗口，按 Ctrl+V 粘贴。按 H 则取回首卡。

同一菜单还可新建快速笔记、打开全局设置（S）或退出（X）。有隐藏的悬浮卡片时，会出现显示一张隐藏的悬浮卡片；每次选择会尝试恢复一张，多张隐藏时会轮流尝试。这些单键仅在托盘菜单打开时生效。

在通知区域用键盘选中 ClipRope 后按 Enter，和左键单击图标一样会切换工作区。中键没有绑定操作。如果 Windows 资源管理器重启，ClipRope 会重新添加托盘图标。
