默认快捷键与生效范围

ClipRope 桌面应用的默认键位
快捷键操作生效范围
Ctrl+Shift+V显示或收起工作区全局
Ctrl+Shift+Space新建悬浮快速笔记全局
Tab切换到下一条收集绳指针位于可见绳子行，或工作区获得焦点
Ctrl+Tab切换单绳视图与总览与 Tab 相同
Ctrl+F查找卡片与 Tab 相同
Ctrl+S / Esc保存 / 取消本次文字编辑卡片文字编辑器

网页手册用 Ctrl+K 搜索文档。桌面应用的默认组合键可在全局设置 → 快捷键中调整。

在桌面应用中查找卡片

打开工作区，将指针移到绳子行上并按 Ctrl+F，或在绳子菜单选择查找卡片。输入文字、链接或部分文件路径，按 Enter 跳到下一处，按 Shift+Enter 回到上一处，按 Esc 关闭查找。

单绳视图只查找当前绳上的卡片。总览可跨绳查找，回收绳显示时也在范围内。查找依据卡片已保存的信息，不会读取文件正文或识别截图中的文字；浏览匹配项会保留收集绳和剪贴板。

双击后没有看到粘贴内容

卡片回到绳首，目标位置仍为空
先在全局设置 → 卡片检查是否选择了“仅复制”。如果已复制，点回正确的输入位置按 Ctrl+V。自动粘贴要求原输入区域仍然有效。
看到“已复制，已发送粘贴快捷键。”
先检查目标位置，避免重复粘贴。目标应用决定接收哪种格式；可以用记事本验证文字，用资源管理器的文件夹接收文件、文件夹或截图 PNG。
看到“剪贴板发布失败，卡片仍然可用。”
此次未能恢复卡片内容。回到绳上重试；如果卡片引用文件，可先确认原文件仍在原位置并且可以访问。

常见问题

关闭的悬浮卡片在哪里？
默认在回收绳的首位。显示回收绳并找回卡片
为什么滚动时切换了绳子？
单绳视图中普通滚轮浏览卡片，按住 Ctrl 滚动会切换收集绳。查看两种视图的滚轮操作
重启后还能找到卡片吗？
已保存的绳上记录和悬浮卡片会随本机历史重新加载。引用外部文件的卡片仍依赖原文件。查找当前数据目录
